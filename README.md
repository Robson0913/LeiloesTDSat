# Sistema de Leilões – Projeto Java

## 📌 Descrição do Projeto
Este projeto consiste no desenvolvimento de um sistema informatizado para uma casa de leilões, com o objetivo de auxiliar na organização e no controle de suas rotinas.  
O sistema permite o gerenciamento de informações relacionadas aos leilões, utilizando um banco de dados integrado e uma aplicação desenvolvida em Java.

O projeto foi versionado utilizando o Git e hospedado no GitHub, seguindo boas práticas de controle de versões e garantindo maior segurança, organização e facilidade de colaboração.

## 🛠️ Tecnologias Utilizadas
- Java  
- MySQL  
- JDBC  
- Git  
- GitHub  

## 📂 Estrutura do Projeto
- Código-fonte desenvolvido em Java  
- Banco de dados MySQL importado a partir de script SQL  
- Controle de versões realizado por meio do Git Bash  

## 🔄 Versionamento
O versionamento do projeto foi realizado utilizando os seguintes passos:
- Inicialização do repositório local com Git  
- Adição dos arquivos do projeto ao controle de versões  
- Realização de commits para registro das alterações  
- Criação de repositório remoto no GitHub  
- Sincronização entre repositório local e remoto
